# 仓储拣选设计实验室 · 给大家的体验指南

因为做的内容是给实际仓储场景的，所以有不少术语、缩写，为了方便大家了解体验，给大家准备了体验说明

## 开始前

打开 [仓储拣选设计实验室](http://127.0.0.1:8765/)。本应用在当前电脑运行；体验时需要保持本地服务开启。建议首次保持 R01，其余筛选先用默认值。

完整体验约 6—8 分钟。时间有限时，优先体验“风险与证据”的原始事件、LI 演示和上下文证据助手。

## 五个页面的内容

- **项目总览**：了解项目关注什么、已有多少数据，以及结果的适用边界。
- **仓库调查**：把库位、商品、事件与路线放到真实仓库地图上，查看哪些位置对当前指标贡献较大。
- **风险与证据**：查询精确事件，展开计算参数与方法来源；还可以独立体验标准化任务 LI 计算和上下文问答。
- **方案实验**：比较已保存方案与同一数据范围下的 S0 基线，查看指标、布局变化及移动商品。页面不会重新搜索布局。
- **方法与记录**：查阅方法含义、版本、来源和验证记录，帮助理解哪些结论有依据、哪些仍未评估。原仓储数据的说明与新增 LI 演示应分开理解。

## 推荐体验流程

### 1. 项目总览

 浏览主要指标与说明，了解系统同时关注作业路程和条件性筛查结果。

### 2. 仓库调查：从地图找到具体对象

**点击：** 左侧“仓库调查”，保持 R01。点击地图上的一个库位单元，或点击下方“库位贡献排行”中的库位。

**体验：** 查看所选位置的商品、货架层级和事件列表。再将“着色指标”切换为“事件数”或“筛查覆盖率”，观察同一仓库在不同指标下的分布。

**操作：** 先看图例，再看选中对象。深色表示当前指标数值较高；缺失或未评估不能当成低风险。

### 3. 风险与证据

**点击：** 左侧“风险与证据” → “起点控制示例” → “展开完整计算与证据链”。

**体验：** 从 FILI 和 FIRWL，追溯搬运重量、两端手部几何、计算乘数与来源片段。抽屉内可点击“计算参数”“方法依据”等章节，查看具体依据。

**再试一次：** 关闭抽屉，点击“unknown 抓握示例”。此时会看到“未评估”与缺失原因，说明信息不足时系统会保留空值。

### 4. 标准化任务 LI 评估

**点击：** 在“风险与证据”页向下找到“标准化任务LI评估”。

- 选择预设 A，保持默认重量约 **19.958 kg**、频率 **0.2 次/分钟**，点击“计算 RWL / LI”。结果约为 **RWL 6.283 kg、LI 3.177、FM 1.000**。
- 把重量改为 **40 kg**，再次计算。RWL 保持不变，LI 升至约 **6.366**，观察重量对指数的影响。
- 保持 40 kg，把频率改为 **5 次/分钟**，再次计算。FM 变为 **0.800**，RWL 约 **5.026 kg**，LI 约 **7.958**。
- 把频率改为 **20 次/分钟**，再次计算，查看越界原因与“未评估”。也可清空重量，体验缺失输入提示。
- 切换预设 B，再点计算，比较另一组几何与抓握条件。展开“明确设定的适用条件与来源”，查看完整设定。

**怎么看：** RWL 是该设定任务的推荐重量限值；LI = 搬运重量 ÷ RWL；FM 是频率乘数。LI 大于 1 表示超过该设定任务的推荐限值，不能直接解释为伤病概率。

### 5. 方案实验：同时看结果和空间变化

**点哪里：** 左侧“方案实验”，设置 **R01 / test / K20**，在“已计算方案”中选择 **S3_K20_w50_s51003**。

**体验：** 上方自动展示所选方案与同一 run、同一 split 的 S0 基线对比，无需另行选择 S0。向下查看前后地图；再点击“移动清单与事件配对”中的一个 SKU，查看它从哪里移到哪里，以及相同提举任务的前后参数。

**再试一次：** 保持 R01 / test / K20，切换 S1 方案，观察路程与筛查代理量可能朝不同方向变化

### 6. 上下文证据助手

**点击：** 返回“风险与证据” → “起点控制示例” → 页面右上方“上下文证据助手”。

**怎么提问：** 保持默认 B2 检索方式和当前事件 ID，输入：

“当前事件为什么FILI大于1，哪个端控制？”

点击“检索证据并提问”，等待回答，再查看引用和依据。也可以比较 B1、B2 两种证据组织方式；切换后需要重新提交。

**体验：** 助手先读取当前对象与真实证据，再调用 DeepSeek 组织回答。留意界面上的缓存、生成、证据不足或校验提示；回答内容和耗时可能变化，不能保证每次都成功。

**使用提醒：** 因为此步骤产生真实 API 消耗，引用与校验提示帮助核对回答，若助手不可用，仍可继续浏览事件和方法依据。

### 7. 方法与记录

**点击：** 左侧“方法与记录”。

**体验：** 查看 FILI 的定义、仓储正式 LI 未评估的原因、原始作业与回放的区别，以及版本和来源记录。将这里的仓储主数据说明，与独立的标准化 LI 演示区分开。
